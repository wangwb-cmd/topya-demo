我的游戏分区展示 · 产品需求文档（PRD）

一、需求概述（功能清单）

本期范围
  • My Games 页展示“我的收藏”和“已下载的游戏”两个分区，前者始终在前。
  • 收藏按收藏时间倒序；已下载游戏优先按最近 N 天有效游玩时间倒序，无有效游玩记录时按下载完成时间倒序。N 从 Remote Config 获取，默认 3 天。
  • 分区无游戏时隐藏该分区标题；两区均为空时沿用旧版整页空态。
本期暂不展开
  • 不改首页推荐排序、下载管理页、游戏详情和游戏启动流程。
模块一级功能说明
1我的收藏展示用户已收藏游戏，最近收藏在前。
2已下载的游戏展示本机下载完成及预下载完成的游戏，并按有效游玩与下载完成时间排序。
3空态和同步零数量时隐藏相应分区；收藏、取消收藏、下载、删除后刷新。

1.1 共享规则

维度规则说明
分区顺序我的收藏 → 已下载的游戏两个分区均有数据时固定顺序。
跨区去重同一游戏同时收藏且已下载时只出现在“我的收藏”取消收藏后，若本地包仍有效，游戏进入“已下载的游戏”。
有效游玩单次游戏时长达到 30 秒即计入正常退出和异常退出、杀进程均计入；以设备本地时间记录。杀进程后应在下次启动时恢复已达到 30 秒的游玩记录，不依赖正常退出回调。
有效游玩窗口最近 N 个本地自然日，含当天；Remote Config 默认 N=3配置值应为正整数；无配置或值无效时使用 3 天。按设备本地日期筛选有效游玩记录。
下载资格本机游戏包下载完成或预下载完成且可启动下载中、预下载中、失败、暂停和已删除文件不计入。
排序稳定性游玩时间相同按下载完成时间倒序，仍相同按游戏 ID 升序避免列表刷新时同时间记录抖动。

二、详细方案

一级模块二级功能原型描述
1
My Games		1.1 双分区展示打开交互原型
【页面元素】

1、底部仅保留 Home 与 My Games；My Games 激活。

2、“我的收藏”位于“已下载的游戏”上方；各分区使用现有双列游戏卡样式。

【交互说明】

1、点击游戏卡进入现有游戏启动流程；星标切换收藏状态并立即更新本页。

2、在 Home 与 My Games 之间切换时，重新读取当前收藏和下载状态。

【功能逻辑】

1、收藏列表按收藏时间倒序，最近收藏在最前；同一游戏不在下载区重复展示。

2、下载区优先展示最近 N 个本地自然日内有单次至少 30 秒有效游玩的游戏，按最近一次有效游玩时间倒序；其余游戏按下载完成时间倒序。N 由 Remote Config 配置，默认 3。

3、预下载完成且可启动的游戏与普通下载完成游戏同样参与下载区排序。

【边界说明】

1、收藏游戏未下载完成仍展示在收藏区，卡片保留现有下载入口。

2、下载文件被删除或失效后，游戏从下载区移除；若仍被收藏，保留在收藏区。

3、正常退出与杀进程都按本地记录的单次时长判断，达到 30 秒计入有效游玩。

2
空态		2.1 分区显隐与整页空态打开空态原型
【页面元素】

1、单个分区无游戏时，隐藏该分区标题和内容，不占位。

2、两区均无游戏时沿用旧版游戏机插图、标题“还没有游戏”、副文案“将喜欢的游戏添加到这里，方便快速访问。”及“添加游戏”按钮。

【交互说明】

1、点击“添加游戏”切到 Home。

2、收藏或下载状态变化后立即重算两个分区和整页空态。

【边界说明】

1、仅收藏区为空时只显示下载区；仅下载区为空时只显示收藏区。

实现说明：当前参考工程的 RecentGamesStore 只保留最近 10 个游戏，且游戏结束时才写入记录。研发需补充可覆盖全部已下载游戏的近 N 天有效游玩记录，并在达到 30 秒时持久化，确保杀进程后仍能计入。原型中的游玩与预下载状态均为评审模拟。
